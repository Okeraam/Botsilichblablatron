# Robot sounds

Add one MP3 file for each command. Keep these filenames so the buttons can find them automatically:

- `dance.mp3`
- `self-destruct.mp3`
- `secret.mp3`
- `shoot.mp3`
- `turn-on.mp3`
- `turn-off.mp3`
- `flip.mp3`
- `greeting.mp3`
- `jump.mp3`
- `laser.mp3`
- `soundtrack.mp3` (background music and the Rhythm Game song)

The robot's greeting also uses your browser's Spanish text-to-speech voice when available.
